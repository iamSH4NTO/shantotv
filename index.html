Frequently Asked Questions

How do I install Shanto TV on macOS?
  1. Download the .dmg package matching your processor type (Apple Silicon M1/M2/M3/M4 or Intel).
  2. Double-click the downloaded .dmg file to mount it.
  3. Drag the Shanto TV icon into your Applications folder.
  4. If macOS Gatekeeper blocks opening, go to System Settings > Privacy & Security and click Open Anyway, or right-click the app icon and select Open.
How do I install Shanto TV on Windows?
  1. Download the Windows Setup (.exe) or Portable (.exe) version.
  2. Run the installer. If Windows Defender / SmartScreen presents a warning prompt, click More Info and then select Run Anyway.
How do I run Shanto TV on Linux?
  1. Download the Linux AppImage or Tarball (.tar.gz).
  2. For AppImage: Make it executable via terminal (chmod +x SHANTO_TV-1.0.0.AppImage) or right-click Properties > Allow executing file as program.
  3. Double-click to launch.
How do I install the Shanto TV APK on Android?
  1. Click the Download Shanto TV APK button under the Android tab.
  2. Open the downloaded .apk file.
  3. Enable Unknown Sources in your Android device settings if prompted, then click Install.
Is Shanto TV safe and free to use?
Yes! All application packages are scanned for security before release. Shanto TV is 100% free with no registration or hidden fees.
